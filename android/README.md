# 本地音乐解码 Android 版

这是 `kugou-unlock` Python 工具的原生 Android 首版迁移工程。目前实现 KGG、KGM、
KGMA、VPR 和已是明文的受支持音频，并通过 Storage Access Framework 处理用户手动
选择的文件。目标 root 虚拟机可使用只读默认路径或自定义路径；手动歌曲/密钥输入通过
`ACTION_GET_CONTENT` 显示应用选择器，歌曲文件夹和输出目录通过系统目录选择器授权。

## 首版安全边界

- APK 不申请 `INTERNET`、传统存储或所有文件访问权限。
- 首次进入必须分别确认“只处理本人拥有或获授权的文件”和“密钥来自本人控制的设备或
  合法授权来源”；确认前不会调用 `su`。应用不提供、下载、共享或维护公共密钥库。
- 产品主要面向已 root 的 Android 虚拟机。用户同意首次声明后，通过 `su` 只读检测并
  自动加载已知默认歌曲目录和密钥；仍可手动修改路径，不使用 Shizuku 或 ADB。
- 默认歌曲目录为 `/storage/emulated/0/kgmusic`；默认检查正式版与概念版的
  `mggkey_multi_process`。歌曲目录和密钥文件路径都允许用户编辑。
- 导入歌曲时启用 `EXTRA_ALLOW_MULTIPLE`，用户可自行选择 MT 管理器等外部文件管理器，
  并兼容管理器返回的单个 URI 或 `ClipData` 多选 URI。
- 导入密钥时强制显示应用选择器；用户可自行选择已安装的 root 文件管理器。外部文件
  管理器只向本应用返回用户选中的单个只读 URI，本应用不会获得其 root 权限。
- 输入 URI 始终只读；输出使用临时 Document，验证成功后再改名或复制为最终文件。
- Root 来源只执行存在性检查、`find` 和 `cat`，路径经过 shell 参数转义；不修改、删除、
  移动或重命名酷狗文件。
- 重名文件默认跳过；可在顶部 ⚙ 中关闭跳过并改用自动编号，始终不覆盖已有内容。
- 默认路径中的 `mggkey_multi_process` 在首次声明同意后自动解析；手动选择或修改的
  `mggkey_multi_process` / `kgg.key` 仍要求二次确认。
- 密钥映射只驻留当前应用进程，不保存到磁盘，也不进入系统备份。
- 首版不包含歌词、封面、数据库、标签写入或网络补全。

## 已迁移模块

- 内容优先的音频与加密类型识别。
- KGM/KGMA/VPR version 3 流式解码。
- KGG mode 5、TEA、QMC2 Map/RC4 与 legacy same-shift 探测。
- 未加密 MMKV 与文本 `kgg.key` 的有界解析。
- Compose 四 Tab 界面（歌曲、密钥、输出、处理）、批量处理、取消、逐项结果和 SAF 原子输出。
- Root 默认路径自动加载、自定义路径、递归歌曲扫描和手动密钥来源二次确认。
- 歌曲“选择文件”和“选择文件夹”两个独立入口。
- Root 歌曲与密钥路径默认折叠；界面使用用户提供的音乐图案作为低透明度背景。
- 批量处理按设备能力使用 2–4 个并行任务，并按输入字节汇总显示整体进度。
- 顶部 ⚙ 设置默认开启“跳过同名文件”；关闭后恢复自动编号且仍不覆盖源文件。

最低 Android 版本为 API 26。算法测试使用合成数据与由 Python 基线生成的固定向量，
不包含真实歌曲、真实密钥或个人数据。

Windows 构建建议使用只含英文字符的仓库路径。工程已允许 Android Gradle 在中文路径
编译，但部分 Gradle 测试工作进程仍可能无法正确处理非 ASCII 类路径。
