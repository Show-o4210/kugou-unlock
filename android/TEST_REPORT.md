## Root 与新版 UI 候选版（已由下方体验优化版取代）

- 文件：`app/build/outputs/apk/debug/app-debug.apk`
- SHA-256：`D1F679A86C66B4F20ADDDAB80C1EF8255B332F81C09D9826192B3C916CF8A2D7`
- 大小：13,969,022 字节
- 目标环境：已 root 的 Android 虚拟机

该候选版会调用 `su`，但只用于默认路径存在检查，以及用户点击后执行只读目录扫描或
读取指定文件。默认歌曲目录是 `/storage/emulated/0/kgmusic`；默认密钥候选覆盖正式版和
概念版包名在 `/data/user/0` 与 `/data/data` 下的 `mggkey_multi_process`。所有路径均可
编辑，传入 shell 前会作为单个字面量转义。

歌曲输入已拆分为“选择文件”和“选择文件夹”：前者使用 `ACTION_GET_CONTENT` 并允许
多选，后者使用 `ACTION_OPEN_DOCUMENT_TREE` 递归加入文件。自动检测不读取文件内容；
扫描 root 歌曲目录需要用户点击，读取 root 密钥还需要在显示准确路径后再次确认。

首次进入新增两项必须勾选的本地使用声明：用户分别确认文件使用权和密钥来源；未确认时
“同意并继续”不可用，也不会调用 `su`。应用明确声明不提供、下载或分享公共密钥。

界面已拆分为歌曲、密钥、输出、处理四个 Tab，Root 歌曲路径和密钥路径默认折叠；用户
提供的音乐图案以低透明度背景显示，卡片叠加 Material 表面色保证文字对比度。

2026-09-28 已通过 ADB 安装到当前虚拟机进行界面验证：设备报告 Android 9（API 28）、
型号 `25060RK16C`、制造商 `REDMI`。已确认首次声明的禁用/启用状态、确认后才进行 Root
检测、四个 Tab、折叠与展开路径以及背景可读性。Root 检测报告可用；本轮没有读取真实
歌曲或密钥，也没有验证默认私有路径命中、目录扫描、密钥解析或实际歌曲解码。
